# Maintainers & Ownership — SAGAPI

## Teams recommandées (GitHub org)

- `@OurITRes/sagapi-maintainers` : ownership global, merges, releases
- `@OurITRes/sagapi-security` : revue sécurité, triage vulnérabilités
- `@OurITRes/sagapi-backend` : ownership backend
- `@OurITRes/sagapi-frontend` : ownership frontend
- `@OurITRes/sagapi-infra` : ownership infra

## Permissions (recommandé)

- Maintainers : Admin/Maintain
- Security team : Maintain (au minimum) + accès Security Advisories
- Contributeurs : Write/Read selon besoin
