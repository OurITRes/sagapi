# Issue templates — Guide

SAGAPI utilise les **Issue Forms** (YAML) dans `.github/ISSUE_TEMPLATE/`.

## Objectifs

- Récolter des rapports plus exploitables (bug/feature)
- Éviter les issues “blank”
- Rediriger les vulnérabilités vers un canal privé

## Fichiers

- `config.yml` : désactive les blank issues et ajoute des `contact_links`
- `bug_report.yml` : formulaire bug
- `feature_request.yml` : formulaire feature

## Sécurité

Pour une vulnérabilité : **ne pas ouvrir d’issue**.
Utiliser “Security vulnerability (private)” (Security Advisory) ou suivre `SECURITY.md`.
