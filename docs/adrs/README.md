# ADRs (Architecture Decision Records)

Les ADRs documentent les décisions importantes
(authN/authZ, secrets, stockage, flux, etc.).

## Règles

- 1 décision = 1 ADR
- Lier l’ADR à l’Issue/PR/Project
- Inclure impacts sécurité (Zero Trust, moindre privilège, audit)

## Template

Utilisez `docs/adrs/ADR-0000-template.md` comme base.
